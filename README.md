# Shattered Realms — 3D Frontier prototype

A browser-based third-person 3D exploration slice. The terrain, forest, village, ruins, river, NPCs, shrines, crystal quest and archive gate are rendered with Three.js. Uses CDN-hosted Three.js (internet required).

## Controls
- WASD / arrows: move
- Mouse drag: orbit camera
- Shift: run
- E: interact
- Space: quick dodge
- Esc: close dialogue

## Deployment
Upload the contents of this folder to the root of the existing GitHub repository. Render will build using the included Dockerfile. This prototype is not photorealistic or full-featured multiplayer yet; it is a 3D playable foundation.
